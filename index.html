Project overview

Contractor Manpower Mobilization Platform, an enterprise web application and mobile app that replaces the current Google Sheets / Google Forms / Excel setup used to onboard contractors and mobilize their manpower across BPCL and other project sites.

The existing system works, but it has reached its limits as data has grown:

Slow at scaleHeavy data validation on sheets makes loading and entry slow as records grow across projects.
Not mobile-friendlyContractors, security and site teams can't easily update or verify status from a phone.
Weak access controlSheet-level sharing can't restrict what each contractor sees, and deletions can't be traced.

Scope of work

Mobilization

Contractor onboarding
  • Admin creates contractor with email ID; system emails a secure invite link
  • Contractor logs in to their own portal and their onboarding journey starts
  • Each contractor sees and manages only their own manpower
Manpower registration
  • Single-candidate entry form or bulk Excel upload
  • Mandatory fields with instant validation (12-digit Aadhaar, PAN format, mobile, DOB, etc.)
  • Auto-generated unique ID for every person
  • Document uploads per candidate
Mobilization workflow & status tracking
  • Stage-wise status for every worker, visible to management in real time
  • Security check & police verification tracking
  • Pending / complete indicators at every step
  1. 1Registration
  2. 2Documentation pending
  3. 3Documentation complete
  4. 4Security / police verification
  5. 5Gate pass
  6. 6Mobilized
Gate pass & accommodation
  • Gate pass generation, activation and closure
  • Security / gate view to check a person's status by ID
  • Accommodation and room allocation tracking
Masters
  • Projects / sites, contractors, manpower grades & designations (GM, DGM, engineers, supervisors, associates, skilled / unskilled)
  • Trades, document types, workflow stages
  • User access master
Data migration
  • Import of existing BPCL project data from the current Google Sheets / Excel
  • Same structure reusable for every new contract and project

Platform

Role-based access control
  • Admin, editor, commenter and viewer roles, plus custom per-module permissions
  • Contractor-scoped data access
  • Full audit log: who created, edited or deleted what, and when
Dashboards & reports
  • Live mobilization dashboard by project, contractor, grade and stage
  • Filters, search and export to Excel / PDF
Mobile apps
  • Android and iOS apps with the same core features as the web app
  • Published on Google Play Store and Apple App Store
Security & performance
  • Encrypted data in transit and at rest, secure login
  • Daily automated backups
  • Fast loads even with large data volumes
